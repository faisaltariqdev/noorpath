## Weekly Audit Protocol
1. **Frequency:** Run once every Tuesday morning at 10:00 AM.
2. **Browsing Mode:** Always use an **Incognito / Private Window** to prevent personalized search or browsing cache bias.
3. **Tracking Metrics:**
   - **Mentioned (Y/N):** Was NoorPath explicitly named in the answer text?
   - **Citation URL:** Did the AI include a clickable source badge or link back to `noorpath.online`?
   - **Competitors:** Note which competitors appeared alongside NoorPath to detect ranking shifts.
